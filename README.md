# Social Media Performance Data Analysis
This project analyzes social media performance data to measure engagement, reach, and content effectiveness. It leverages **Excel, Power Query, SQL, Python, and Power BI** to clean, process, and visualize data, providing a clear view of what drives audience growth.
##  Objectives  
- Clean and preprocess raw social media data  
- Perform exploratory data analysis (EDA)  
- Identify top-performing posts and engagement drivers  
- Build an interactive **Power BI dashboard**  
- Provide insights to guide content strategy and growth  

## 📂 Dataset  
- The dataset contains **post-level metrics** such as:  
  - Likes  
  - Comments  
  - Shares  
  - Impressions  
  - Engagement rate   

## 🛠️ Tools & Technologies  
- **Excel & Power Query** → Data cleaning & transformation  
- **SQL** → Querying structured data  
- **Python** → Data analysis & visualization (Pandas, Matplotlib/Seaborn)  
- **Power BI** → Interactive dashboard

### Key Insights:  
-Instagram leads with 135K engagements, followed by Facebook (110K); Twitter lags behind (55K).
-Polls & videos drive the highest engagement, while text-only posts underperform.
-Positive sentiment dominates at 46%, but neutral/negative reactions (27% each) show room for improvement.
-Best posting times are late night and mornings; evenings underperform.
-Engagement is declining since July, mostly in likes → need fresh creative strategies.
